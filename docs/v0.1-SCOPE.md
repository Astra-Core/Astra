# Astra v0.1 Scope and Known Limitations

## In Scope

- Snapshot-only Postgres → Postgres/Snowflake
- Control-plane APIs
- Local worker
- Web UI basics
- No CDC

## Known Limitations

- No CDC execution
- No schema evolution
- Local-only staging
- No distributed workers
- UI WIP

## Future Work

- CDC
- Destinations
- Cloud deploy
- etc.
